# 查找、高亮、比较、终端与聊天内存优化

2026-11-07。本轮覆盖 Pencode、本地替换依赖 `../onix` 的 `syntax` 包，以及 `extensions/codex` 子模块，三处改动需要一起保留。已有的终端清空行为和其他本地修改继续保留，本轮未执行提交操作。最终检查时，Onix 的相关修改已包含在本地提交 `514ca9f`，Pencode 和 Codex 仍为工作区改动。

## 六项改动

1. **释放查找缓存**：关闭查找栏、关闭被搜索文档，以及切换到会隐藏查找栏的界面时，清理缓存快照、匹配和选区引用。大匹配数组直接释放，小数组继续复用。用选区初始化查询时复制查询字符串，避免短查询引用整份大文档。
2. **收缩高亮数组**：Onix 的词法结果、行状态、样式结果，以及协议两端的 capture 数组，在容量超过 `max(4096, 当前条目数 × 4)` 时收缩；移除条目的引用及时清空。普通编辑继续复用容量。
3. **限制比较临时存储**：高亮线程的两份交换结果分别限制 diff 行、布局、块及变更数组的总容量；超过 1 MiB 时释放。行内比较临时数组另有 1 MiB 预算，超大的行首索引也会释放。小型比较通过预热后零分配检查。
4. **紧凑终端历史**：历史单元从 28 字节改为 16 字节，样式标志打包，组合字符按需放进稀疏表；活动屏幕仍可直接修改。历史扩容不超过行数上限，保持顺序、颜色、宽字符和组合字符。`HistoryRow` 返回复用的解码行，有效期至下一次 `HistoryRow` 或 `Resize`。
5. **高亮和查找直接读取快照**：工作线程、语法协议两端和 Onix 词法器使用不可变快照，仅传输编辑区间、读取待解析行。超长行沿用原有解析预算，并限制跨块复制大小。查找按块读取字面量、按 rune 做 Unicode 折叠，正则使用快照 reader，保留断言、捕获组和空匹配语义。源码 diff 的字符串接口和替换流程仍可能请求完整字符串。
6. **限制聊天冷缓存并减少 HTML 组装**：可重新加载的后台会话最多保留 4 个、估算记录数据合计不超过 1 MiB，按最近查看顺序淘汰；可见、运行中、观察中、等待审批及编辑中的会话受保护。淘汰保留草稿，再打开时通过既有历史恢复路径加载。清理不可见渲染缓存，聊天主体和历史列表使用同一个 builder，减少一次完整主体复制。

聊天仍然生成完整 HTML 视图，并由现有 SDK 比较区域；本轮没有增加直接发布局部区域的新协议。

## 对照测量

Linux amd64，Intel i5-11500，Go 1.27.3。通过临时 Go overlay 恢复本轮修改前的实现，保留其他本地改动，得到对照版本。下面前三项和终端项测量仍被引用的底层数组／文本容量；基准项测量每次操作的累计分配，**均不是进程 RSS**。

| 场景 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 搜索 16 MiB 文档后关闭查找和标签：查找缓存快照 | 16,777,216 B | 0 B |
| 10 万行源码缩至 13 字节：词法与服务端 previous 数组 | 19,800,208 B | 536 B |
| 10 万行比较完成后重置结果：行和布局索引 | 9,609,152 B | 0 B |
| 120 列、2000 行终端历史 | 6.422 MiB | 3.662 MiB |
| 200 列、2000 行终端历史 | 10.820 MiB | 6.104 MiB |

终端数字使用普通无组合字符的输出，统计历史数组容量，不包含活动屏幕、解码行及按需组合字符表。

协议高亮基准预热后在同一位置交替替换一个字符，复用请求和响应缓冲，每个尺寸计时 20 次；聊天基准重复组装包含 100 条已缓存消息的视图，每条消息 500 字节，计时 20 次。聊天基准只覆盖视图构造，不包括 SDK 编码、IPC 和宿主渲染。

| 基准 | 优化前 B/op | 优化后 B/op | 优化前 allocs/op | 优化后 allocs/op |
| --- | ---: | ---: | ---: | ---: |
| 64 KiB 源码单字符编辑 | 74,610 | 2,928 | 14 | 38 |
| 2 MiB 源码单字符编辑 | 2,106,219 | 4,368 | 14 | 53 |
| 聊天视图重复组装 | 349,707 | 74,304 | 20 | 3 |

不可变文本树需要为修改路径分配节点，因此增量高亮的分配次数有所增加，分配字节数显著下降。没有把整次编辑或整个工作台帧称为零分配。未修改的高亮、预热后的字面量搜索、小型比较、普通终端滚动及历史读取有独立的零分配回归检查。

```sh
# extensions/codex 目录

```
