# Terminal symbol fallback

`SymbolsNerdFontMono-Regular.ttf` is the unmodified Symbols Nerd Font Mono
from [Nerd Fonts v3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly).
It supplies missing shell prompt icons (Python/Conda, Git, Powerline and others)
without requiring a patched system font. Pencode embeds and shares this face;
the user's selected font retains its own text glyphs and line metrics.
